## 2. Checks performed with no defect found

- **Effect cleanup, StrictMode and listener leaks:** every `addEventListener`, `setInterval`, `setTimeout`, `IntersectionObserver`, `MutationObserver` and rAF created in an effect is released in that effect's cleanup (`useActiveSection`, `useHashScroll`, `useInView`, `useParallax`, `usePrefersReducedMotion` including the legacy `addListener` path, `useReveal`, `useScrolled`, `useTheme`, `useTypewriter`, `CursorGlow`, `Speedometer`, `Nav`). Each one survives mount, cleanup and mount. In `useTypewriter`, the cursor ref is mutated only inside timer callbacks, so StrictMode's cancelled first pass leaves it untouched. Scroll and mousemove listeners are passive.
- **rAF:** `Speedometer` is the only rAF user (`grep`). The loop runs only while `inView && !reduced`, resumes from `tRef`, and the closure-held `id` is cancelled on cleanup. Under reduced motion it shows the static t=0 frame.
- **Stale closures:** `toggle` is stable (`useCallback([])` with a functional update). The scroll handlers read live DOM and `window.scrollY`. Theme intervals depend on `[manual, geo]`.
- **Lazy sections and reveal:** each `Section` owns its `useReveal(ref)`, so a lazy section's `.reveal` elements are observed when it mounts. Without an IntersectionObserver, or when its constructor throws, all of them get `visible`. The class strings and stagger indices match FR-FX-005 and the baseline.
- **Hash re-scroll (`useHashScroll`):** arms only while placeholders exist. The ready test uses `compareDocumentPosition`. It disarms on wheel, touchstart, keydown, timeout and hashchange re-arm, and catches malformed `%` escapes. The skip link's `#main` resolves at once with no scroll, because `main` contains the placeholders.
- **Theme before paint:** `useLayoutEffect` sets `html[data-theme]` before paint (FR-THEME-001). Storage access is fully inside `try`, including the `globalThis.localStorage` getter, and nothing is logged.
- **Reduced motion:** `CursorGlow` is not mounted, the parallax is disabled with its transform reset in cleanup, the typewriter shows a static first role, and the gauge is static. The CSS block comes last in `sections.css`.
- **Escape and focus return, skip link:** the keydown listener exists only while the menu is open, and Escape closes the menu and focuses the hamburger. The skip link is the first focusable element, `<main id="main" tabIndex={-1}>` is in place, and `.skip-link` and `:focus-visible` exist in `base.css`.
- **Security:** no `dangerouslySetInnerHTML`, `eval` or `new Function`. All four `target="_blank"` sites carry `rel="noopener noreferrer"` (Button, Contact, Design, Resume). Every data URL goes through `assertUrl` (SUDS 4.4). Design hrefs must use https, and ContactLink's `external` must be true exactly for https links. Simple Icons slugs are constrained by `ICON_REF_RE`. `RichText` renders React text nodes only.
- **Markup and text parity against the baseline:** the section roots and elements (`section`/`div`), the `.inner` wrappers, the class token order (`project-card reveal wide d0`, `behance-card reveal d0 wide`, `edu-card reveal` then `edu-card reveal d1`), the inline styles, the Nav, the mobile menu, the footer and the hero all match. A script found every baseline JSX text node and every quoted string of 12 or more characters in `src` (the one exception is CR-004, composed). All 290 SVG element tags in `customSvgs.jsx`, `DesignArt.jsx` and `Speedometer.jsx` are identical to the baseline, apart from the allowed `ref`/`role`/`aria-label` on the gauge.
- **Error containment:** the per-section `ErrorBoundary` with a placeholder and fallback both keep `id` and `data-section`. The page-level fallback is in `main.jsx`. A failing `onError` is swallowed.
- **Models:** factories validate, reject unknown keys, build in declaration order and deep-freeze. `createSection` freezes shallowly, so `React.lazy` objects stay mutable.
